# Slice 05 choices

- **Density drops the "both share a `patterns` tag" clause.** `mtg/patterns.py` was being built by
  another agent in parallel; add the clause (one more `or` in `scores.density`) once it lands.
- **Interaction rules.** A card *has*: its card types (minus `creature`), subtypes, keywords, the kinds
  of counter it puts (plus generic `counter`) and the types of token it creates (plus generic `token`).
  It *names* any term from the deck's combined has-vocabulary found in its oracle text (plurals,
  Elf/Elves etc.), with its own name masked and its own keywords skipped (every flier says "Flying").
  Alternative: urza's exact tables. Why: reimplemented from the idea only; this set is small and testable.
  Known noise: removal that says "artifact or enchantment" counts as naming artifacts.
- **Printed bands are the player's own decks, not urza's** ("goodstuff ~0.1, tribal ~0.5"). Our metric
  is not urza's: Ayula bear tribal scores 0.21 because plain bears don't name each other, only the
  payoffs do. Printing urza's bands beside our numbers would mislead, so the script prints the
  calibration below.
- **`roles.alternatives` orders most-played first (`order=edhrec&dir=asc`)**, not least-played as the
  spec says, and takes an `exclude` argument. Why: `dir=desc` returns unplayable playtest/joke cards
  (Cursed Firebreathing Yogurt, Giant Mana Cake) first. "Odd" comes from excluding the deck's cards
  and this commander's EDHREC staples instead, so the swaps are real cards that aren't the default.
  Also `not:funny`.
- **`roles.role_of(name)`** (new): the first role in `SHOW` order; `alternatives` needs a role from a name.
- **`staple_share` takes the nonland 99** (the caller filters lands with Scryfall type lines); EDHREC's
  sections can't tell lands it doesn't list.
- **Overlap compares against sibling `.txt` files** in the list's own folder (the player's `decks/commander/`).
- **Swaps:** 3 staples by default (`--swaps`), the most-included staples that have a role, 3 alternatives
  each, no alternative offered twice (Sol Ring and Arcane Signet got the same three before).
