# Slice 02 choices

- **WotC criteria unchanged.** Re-read 2026-10-24: the 2026-02-09 update only adds Farewell and Biorhythm
  as Game Changers and puts bracket changes on hold; the 2025-10-21 update dropped tutor limits and swapped
  "no early-game combos" for "at least six turns" (B3). The format page still says B1–2 have no Game
  Changers and B3 up to three. So the slice's edges stand; FAST (≤ 6 total MV, or Ruthless/Banned) stays
  the proxy for "early". Alternative: model the turn-6 expectation from Spellbook's `speed`; its scale is
  undocumented, so not yet.
- **Official two-card combos come from `/estimate-bracket`** (`definitelyTwoCard`), not from
  find-my-combos' "Infinite" results: Thoracle + Consultation wins without an infinite. The house rule
  keeps using find-my-combos' fast *infinite* combos, so its `!!` text is unchanged.
- **`brackets.house` owns every bracket `!!`**, including the Game Changer cap and the fast-infinite combo
  that `show_combos` used to append; `show_combos` now returns annotated combos and its lines instead of
  printing, so the bracket line can sit right after the Game Changers line. Alternative: leave
  `show_combos` alone and print the bracket line after the combo list (not what the slice asks for).
- **Estimate combos carry `cards` and `bracket`** besides the slice's fields, so `brackets.is_fast`
  works on them unchanged.
- **Chained extra turns = more than one extra-turn card**, for the official bracket as well as the house
  rule. Alternative: count Spellbook combos flagged `extraTurn`; they show up as two-card combos anyway.
- **Without Spellbook** (`--no-combos` or a failed call) the official reason list ends "combos not
  checked" and the line says `Spellbook skipped` / `Spellbook unavailable`; MLD and extra turns fall back
  to `patterns`.
- **No `--verbose` per-card flags** (delegated): the reasons already name the MLD and extra-turn cards.
- **B2 is the floor**: a deck with no Game Changers or two-card combos prints "Official B2", never B1.
