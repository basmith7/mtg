# 10 Forge: choices

- **Timeout default `-c 600`, `-n 10`.** Alternative: Forge's 120 s. Why: spike games took 17–47 s
  with no draws at 600; 120 would cut slow control games for nothing.
- **Deck name mangling:** letters, digits, single spaces (`Krenko Goblins B3`). Alternative: raw names.
  Why: Forge echoes the name as `Ai(n)-<name>` in result lines; punctuation like `–`, `(`, `!` is noise.
- **`A // B` names:** keep for split cards (read from Forge's `cardsfolder.zip`), else front face.
  Alternative: always front face. Why: Forge's DB names split cards `Fire // Ice` and everything
  else by face; the spike lost 4 MDFCs to the full name. `to_dck` stays pure with an optional `split` set.
- **`forge.profile.properties` with `userDir`/`cacheDir` inside the Forge folder.** Alternative:
  Forge's default `~/.forge` and `~/.cache/forge`. Why: the approval covered `~/.local/share/forge` only.
- **`run` takes one deck directory (`-D`).** Why: `SimulateMatch` resolves `-d` names relative to
  `-D`; absolute paths in `-d` fail with "Could not load deck".
- **Docs in `docs/forge.md`**, not `docs/apis.md`. Why: Forge is a local program, not a web API.
