# 09 MCP server: choices

- **Pin a git commit, not PyPI 3.0.0.** Alternative: `--with "selectolax<1"` on 3.0.0. Why: 3.0.0's
  bulk tools (theme, similar) are broken by Scryfall's field rename; the fix is only on `main`.
- **`--exclude-newer` on the uvx line.** Alternative: unpinned transitive resolution. Why: `uvx --from
  git+` ignores `uv.lock`; a date cutoff makes the audited tree the one that runs, and an unpinned
  dependency is what broke 3.0.0.
- **Modules off: EDHREC, Moxfield, 17Lands, Spicerack, MTGGoldfish; on: Scryfall, Spellbook, bulk,
  rules.** Alternative: only EDHREC off. Why: Moxfield is a private API we already have a client and
  rate rules for; the others are draft/constructed data with no Commander use.
