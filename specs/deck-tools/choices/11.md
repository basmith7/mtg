# Slice 11 choices

- **Cast spells count as played.** An instant or sorcery moving hand → graveyard/exile counts, besides
  `PLAY_CARD` and moves onto the battlefield. Alternative: battlefield only (the spec's wording), which
  lists every cast spell as never played. A discarded spell counts too; the log can't tell them apart.
- **"Never played" excludes basics and splits lands from nonland cards**, and the draft's Flopped line
  names at most ten and says the replay can't tell undrawn from held. Alternative: the raw set, which
  reads as a verdict on cards that were never drawn.
- **Fun and Change say "ask the player"** in the draft: only the player knows them.
- **The draft's date is a range** when the games span days (local time, not the API's UTC).
- **Default `--last 5`** games per report.
- **`MTG_REPO` picks the mtg checkout** mtg-table imports (default the main checkout); the player's lists
  are always read from the main checkout's `decks/`. Lets the tools run against a branch before merge.
- **`add_entry` inserts below the fenced format template** at the top of `## Play log`. `render_entry`
  writes "not given" for empty fields, matching the hand-written entries.
